        Scenes
        
  
        A Scene is one interaction — one click, and what should happen afterward. An
    Act puts Scenes in order.
        

  
        Learn a Scene
        
  
        
    
        Marco watches you do it once, with your own hands. Nothing is
      injected, and it reads the words on the screen so it can recognise where it is
      later.
        
    
    
        Pictures are kept — one of each
      screen and one of each control you click, cropped from that window, in this
      machine’s own Marco folder. They are there so you can see what you showed Marco:
      nothing that RUNS reads them, and nothing is ever sent anywhere. Removing the Scene
      removes them.
        
    
        
      
        
    
        
      
      
      
        
    
        
      
      seconds — or press That's it as soon as you are
        done
        
    
        
      
      
    
        
  
        

  
  
        
    
        
    
    
        
    
    
        
    
        Click controls with the mouse — keys are
      watched and cannot name a control.
        
    
    
        Marco has not
      read enough of the screen you started on to recognise it again. Go back to that
      screen and rest there for a moment — an Act that starts on a screen it cannot
      name waits for it instead of pressing.
        
    
    
    
        The recorder
      is a different build from this window, so what it reports may not be what this
      window shows. Close Studio, run plugins/studio/build.cmd, and start it
      again.
        
    
        Marco has not
      read this screen yet. Rest on it for a moment before you click — a press made now
      has nothing to compare against afterwards, so Marco could never tell you whether
      it worked.
