# The skips this gate tolerates, and why.
#
# A `t.Skip` is GREEN, and `go test ./...` prints `ok` over a package in which every test that
# matters declined. So a skip is tolerated here only when it is DECLARED — by package, by test
# name, with a reason somebody wrote — and `cmd/gate` fails on any skip that is not in this file.
#
# It fails on a STALE entry too: one whose test ran and did not skip. A list of excuses nobody
# prunes stops describing anything, and an entry naming a test that has been renamed is an
# exemption doing nothing while the renamed test's next skip arrives undeclared.
#
# A reason beginning `BROKEN:` is a DEFECT, not a decision: a test that no longer establishes what
# it was written for. Those are counted and printed apart on every run, including a green one,
# because they are parked findings rather than settled answers.
#
# Format:  <package> <TestName> — the reason
#
# See [[ADR-264-the-gate-answers-for-what-did-not-run]].
